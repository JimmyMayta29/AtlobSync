¿Mis claves SOL o de API SUNAT se envían a algún servidor?

No. Todas tus credenciales SOL y API SUNAT se cifran con AES-256 y permanecen exclusivamente en la base de datos local de tu computadora. Las consultas hacia SUNAT salen directamente desde tu PC.

La aplicación bloqueará las operaciones hasta que ingreses una licencia comercial, pero todas tus empresas registradas y archivos descargados permanecen guardados de forma segura en tu PC sin perder nada.

Puedes registrar y operar hasta 3 empresas (RUCs) distintas con el 100% de módulos activos (SIRE, CPE PDF/XML/CDR y RHE).
